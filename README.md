## ✨ Overview

A modern and aesthetic **QR Code Generator Web App** that allows users to quickly generate QR codes from any valid URL.
Built with a clean UI, smooth experience, and a stylish **Day/Night mode toggle** for better usability.

---

## 🚀 Features

* 🔗 Generate QR codes instantly from any URL
* 🌗 **Light / Dark mode toggle** (Day & Night aesthetic)
* 🎨 Modern, minimal, and responsive design
* ⚡ Fast and lightweight performance
* 📱 Fully responsive (mobile + desktop support)
* 🧹 Simple and user-friendly interface

## 📦 Installation & Setup

```bash
git clone https://github.com/jacksonvar/QR-Code-Generator-Vibe-Coding.git
cd QR-Code-Generator-Vibe-Coding
```

Open `index.html` in your browser.

## ⚙️ Usage

1. Enter a valid URL
2. Click on **Generate QR Code**
3. Download or scan the QR code
4. Toggle between **Light/Dark mode**
